# Labelling Machine
This project showcases the simulation of a labelling machine using NVIDIA Isaac Sim and Blender   

## Simulation
The Label Machine Movement and the Label Movement can be watched [here](https://youtu.be/-9jzKmZ5iok)

## Description
- **Rotating Flywheel**: Rigged with physics properties such as kinematics, joints, and velocity constraints inside Isaac Sim. This component simulates the mechanical rotation and label dispensing mechanism.
- **Label Strip**: Modeled in Blender and animated to simulate label movement. The animation is exported as a USD file and integrated into the Isaac Sim scene.

## ⚙️ Technical Details
- **Simulation Platform**: NVIDIA Isaac Sim  
- **Modeling Tool**: Blender  
- **File Format**: USD (Universal Scene Description)
